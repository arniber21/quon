# Quon docs

Docs site for Quon, built with [Starlight](https://starlight.astro.build/).

```
pnpm install
pnpm dev
```

## Contributing to the docs

Before adding or revising pages, read the
[documenting Quon guide](https://quon.arnabg.me/contribute/) and the
[style guide](https://quon.arnabg.me/contribute/style-guide/). They define the
page taxonomy, canonical-source rules, local preview, review expectations, and
the writing conventions that keep the docs correct and consistent.

Preview the production build locally with `just ci-website` (or `pnpm build`)
before opening a PR; CI runs the same build on every push.
